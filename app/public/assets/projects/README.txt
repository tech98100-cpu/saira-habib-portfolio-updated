TIPS
------------------
- Recommended size: 1000x700px or similar landscape ratio (crops to fit either way).
- Browser screenshot extensions like "GoFullPage" or your OS's built-in
  screenshot tool both work fine — just make sure the browser window is
  reasonably wide (1200px+) so the site looks like desktop, not mobile.
- Keep the same .jpg extension. If you screenshot as .png, that's fine too —
  the code now tries .png automatically if the .jpg isn't found. Just make
  sure the filename (without extension) matches exactly, e.g.
  "hospital-management.png" or "hospital-management.jpg".
- This file (README.txt) is just for your reference — safe to delete anytime.
